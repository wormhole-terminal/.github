# Wormhole

A fast, native macOS terminal with its own engine, and extras built in. Every terminal is a row in
the sidebar with its live status, including the status of Claude Code, Codex, Gemini CLI and other
agents, and a git panel shows what changed before you commit it.

- **[Download](https://getwormhole.app)**: macOS 14 or later, Apple silicon and Intel. It updates itself.
- **[Source](https://github.com/wormhole-terminal/wormhole)**: Rust on GPUI, GPL-3.0-or-later.
- **[Report a bug or ask for a feature](https://github.com/wormhole-terminal/wormhole/issues/new/choose)**,
  or **[start a discussion](https://github.com/wormhole-terminal/wormhole/discussions)**.

Contributions are welcome: see [CONTRIBUTING.md](https://github.com/wormhole-terminal/wormhole/blob/main/CONTRIBUTING.md).
